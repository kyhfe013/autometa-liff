# 対象者の登録ページ（LIFF）

治療院が渡す QR を LINE で読むと、このページが LINE の中で開き、
「合言葉」と「その人の LINE ID」を治療院の PC へ受け渡す。

- **扱うのは合言葉と LINE ID だけ。** 氏名・生年月日・電話番号・メールアドレスは扱わない。
- 中継（GAS）の控えは、PC が引き取った時点で消える。引き取られない分も 24 時間で消える。

## URL の形

| | |
|---|---|
| 治療院が LIFF に登録する URL | `<公開先>/?l=<LIFF ID>` |
| 患者が読む QR | `https://liff.line.me/<LIFF ID>?p=<合言葉>` |

`l` はエンドポイント側、`p` は QR 側に入る。LINE が両方をこのページへ渡す。
